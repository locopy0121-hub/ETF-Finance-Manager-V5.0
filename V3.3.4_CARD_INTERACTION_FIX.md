# V3.3.4 Card Interaction Hotfix

This OTA specifically fixes the three real-device issues found in V3.3.3:

1. Card dragging fought with the parent ScrollView. Dragging is now restricted to the card's ☰ handle; while dragging, page scrolling is temporarily disabled, PanResponder captures the gesture, and the card visually follows the finger before snapping to the grid on release.
2. The ⚙ icon was decorative only. It is now a real button that opens the dedicated single-card editor.
3. Card content fields had no independent layout layer. Each selected data field now has its own width preset (full / 1/2 / 1/3 / 1/4) and ordering controls. The actual page renderer reads the same fieldSpans configuration, so editor and page output stay synchronized.

Financial data is not deleted or rewritten by these changes. This remains an OTA-only JS/TS update for the existing V3.3.0 APK runtime 3.2.0.
