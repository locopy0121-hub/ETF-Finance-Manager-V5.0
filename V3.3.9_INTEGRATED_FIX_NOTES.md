# ETF財務管家 V3.3.9 — 3.3.6 → 3.3.8 Integrated OTA Fix

## Integration base
- Base: V3.3.8 Dividend Calendar / Widget Safety / Cash Logic.
- Preserves V3.3.7 Widget snapshot/diagnostics, daily P&L history, intraday chart data, mixed chart cards.
- Preserves V3.3.6 card/layout engine, theme/color controls, finance precision rules, market controller.

## Compile fixes
1. `ColorPalettePicker.tsx`: removed invalid `palette.gold` references; uses the established V3 gold `#D4AF37` locally.
2. `screens.tsx`: restored missing `SelectedMetrics` compatibility renderer. It prefers designed page cards when present and falls back to selected metric fields.
3. `widgetTaskHandler.tsx`: added explicit `WidgetStatus` union to prevent string widening into an invalid Widget prop type.

## OTA launcher hardening
- `EAS_NO_VCS=1` is set automatically.
- `EAS_PROJECT_ROOT` is set to the package folder.
- `--environment preview` is explicit, avoiding the development/preview/production prompt on SDK 57.
- Android-only OTA publishing is explicit.
- `npm install`, Expo dependency check, TypeScript check and accounting contract test must all pass before publish.
- `PUBLISH_V3.3.9_OTA.cmd` launches PowerShell with `-ExecutionPolicy Bypass`.

## Compatibility
- Expo runtimeVersion remains `3.2.0` so this OTA targets the existing V3.2 native runtime.
- No native dependency was added or removed in V3.3.9.
