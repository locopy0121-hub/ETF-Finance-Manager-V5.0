## 金融資料誠信規則

- 沒有官方 NAV/iNAV 時，不可把 fallbackPrice 冒充成真實 NAV。V3 詳情頁的 Gauge UI 是監控入口，正式即時判斷須接可靠 NAV 資料源。
- 成分股重疊必須使用真實 ETF 成分與權重資料；未接資料前 UI 明確顯示為預留分析入口。
- 歷史真實回測必須使用真實歷史行情、配息與事件資料，不使用人工隨機曲線冒充回測。
