# ETF財務管家 V3.0.0 建置與測試指南

## 建議流程（Windows PowerShell）

```powershell
cd <V3 專案資料夾>
npm install
npx expo-doctor
npx tsc --noEmit
powershell -ExecutionPolicy Bypass -File .\BUILD_APK.ps1
```

若未安裝 Git，EAS 可採 `EAS_NO_VCS=1`；本專案的 BUILD_APK.ps1 已設定此環境變數。

## V3 需要重新 APK 的原因

V3 正式把 runtimeVersion 提升為 `3.0.0`，Android versionCode 提升為 30，作為新 Native baseline。之後僅 JavaScript/UI/計算邏輯更新可在相同 runtime 下使用 OTA；新增原生套件、權限、Widget Native 設定或 app.json 原生配置時仍須重新 Build APK。

## 首次啟動資料遷移

V3 使用獨立儲存鍵。第一次啟動若尚無 V3 資料，會讀取 V2 的既有 AppState：持倉、配息、費率、每日快照與設定可作為遷移來源。V2 原始儲存不會被 V3 刪除。

## 第一輪實機必測

- 首頁：總資產 / 總投入 / 累積損益數字是否與庫存一致。
- 智慧記帳：同一 ETF 多筆買進是否累加；賣出不可超過持股。
- 配息入帳：Ledger 與現金部位是否同步增加。
- 現金提存：正數存入、負數提領。
- 圖表：首頁投入 vs 資產、資產配置、息收圖、試算圖能正常顯示。
- 背景：4 個內建主題 + 相簿自訂背景。
- Android 底部導航：所有按鈕不得被系統導航列遮住。
- 1–30 秒行情更新：只保證 App 在前景時；Android 背景高頻刷新不假裝由一般 Background Task 保證。

## 尚需真實外部資料來源才能提供的分析

- 成分股穿透與跨 ETF 重疊率：V3 已保留 UI 入口，但需要可靠基金成分資料源後才啟用真實計算。
- 即時 NAV / iNAV：折溢價要以官方或可靠 NAV 資料為準。沒有來源時不可把參考價格冒充 NAV。
- 歷史真實回測：需要完整歷史行情、配息與除權息資料源後才能標示「真實回測」。

這三項不得用假資料偽裝成即時金融資訊。
