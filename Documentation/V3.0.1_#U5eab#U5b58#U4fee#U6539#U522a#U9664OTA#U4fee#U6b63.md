# V3.0.1 庫存修改 / 刪除 OTA 修正

- V3 庫存列新增明顯的 ✎ 修改入口。
- ETF 詳情頁新增「修改庫存 / 購入紀錄」與「刪除庫存」。
- 同一 ETF 的每筆購入紀錄可獨立修改日期、股數、成交行情、手續費。
- 支援新增 / 刪除單筆購入紀錄。
- 儲存後自動重算總股數、成交成本、累積手續費、總投入成本與含費平均成本。
- 同步更新智慧記帳中的買進紀錄，避免首頁總投入成本與庫存成本不同步。
- 刪除整檔庫存前必須確認；只影響 App 資料，不操作券商帳戶。
- 此修正僅 JavaScript / TypeScript，runtimeVersion 維持 3.0.0，可直接 OTA 到已安裝的 V3.0.0 APK。
- 同步修正實機截圖顯示的 Bottom Sheet 底部安全區：設定中心、庫存詳情與庫存編輯按鈕不再被 Android 系統導航列遮住。
