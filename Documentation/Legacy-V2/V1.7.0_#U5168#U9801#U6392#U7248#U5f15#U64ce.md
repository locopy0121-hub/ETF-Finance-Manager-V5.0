# V1.7.0 全頁排版引擎

本版以 V1.6.3 為基礎整合，不刪除既有持倉、購入紀錄、配息、模擬、每日損益、Google Vision OCR 與 OTA 規則。

## 主要修正
- 首頁、持倉、股息、目標、情境、每日損益頁右上角都有排版齒輪。
- 排版編輯器新增搜尋、分類、分類全選/全不選、已選數量。
- 採 6 格網格：整列 6/6、1/2 3/6、1/3 2/6。
- 長按 ☰ 可手指拖曳排序；相鄰且寬度可容納時自動同列。
- 排版資料永久寫入 settings.layout，OTA / 重啟不重置。

## 首頁完整資料庫
包含總資產、持有總成本、成本損益/百分比、含息總損益/百分比、今日損益/百分比、累積/本月/預估年配息、月均現金流、殖利率、本月投入與目標、健康分數、下一筆配置、市場狀態、更新時間等。

每一檔目前持有 ETF 亦可加入個別資料：股數、現價、市值、總成本、平均成本、成本損益、今日損益、配息、殖利率、最後買進日、買進筆數、手續費。

## 持倉完整資料庫
包含股數、成交/含費平均成本、TWSE 現價、市值、總成本、成本/今日/含息損益與百分比、配息、殖利率、目標/目前比重、最後買進日、買進筆數、開高低昨收量、券商、帳戶。

## 其他頁面
- 股息：日期、配息、資格股數、預估配息、狀態、來源、備註與區塊可選。
- 目標：目標、現況、差額、進度、預計時間、假設值、日期、里程碑可選。
- 每日損益：今日/成本/含息損益與百分比、資產、成本、配息、快照日期、走勢圖、ETF 明細可選。
- 情境：組合、壓力測試、定期投入、配置、股息再投入、年度/月度結果、現金流等區塊可選。

## OCR
Google Vision OCR Only 繼續保留。設定頁的 OCR 開關只控制「進階技術設定是否顯示」，不會停用圖片掃描與辨識。

## 相容性
runtimeVersion 維持 1.5.0，屬 JS/TS OTA 更新，不需要重新 Build APK。
