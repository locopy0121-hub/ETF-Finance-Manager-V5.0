# ETF財務管家 V1.8.0 整合升級內容

本版以 V1.7.0 為母版，保留既有持倉、配息、每日損益、目標、情境模擬、Google Vision OCR、Widget、OTA 與資料保護機制，集中整合近期確認的 UI / 計算 / Widget / 通知需求。

## 1. 即時損益與行情
- 開市期間前景更新頻率可設定 1～30 秒。
- App 回前景後依目前設定恢復更新。
- Widget 直接使用 App 最新行情 Snapshot，不另外建立另一套行情來源。
- 新增背景 Widget 任務（Android 系統允許時以 BackgroundTask 更新，最低週期仍受 Android 約 15 分鐘限制）。

## 2. 計算規則統一
- 手續費只存在於「總成本」。
- 純買進成本 = 股數 × 成交行情。
- 總成本 = 純買進成本 + 手續費。
- 即時 / 成本損益 = 市值 - 純買進成本，不再把手續費直接扣入損益。
- 新增與 OCR 匯入後的平均成本以純成交行情為基準；手續費保留於購入紀錄與總成本。

## 3. 數字格式
- 行情、平均成本、百分比：2 位小數。
- 行情欄位不顯示 NT$，只顯示純數字。
- 資產、成本、市值、投入、配息、損益金額：整數顯示。
- 股數：整數。

## 4. Widget
- 修正多 ETF 顯示與欄位套用邏輯。
- ETF 行情 / 股數 / 市值 / 成本 / 今日損益 / 總損益 / 報酬率依設定顯示。
- 新增 Widget 字型比例 80～160%。
- 新增整體靠左 / 置中 / 靠右。
- 保留透明度、指定 ETF 複選、總損益固定顯示。
- App 每次取得新行情會立即寫入 Widget Snapshot 並要求重繪。

## 5. 收盤通知
- 自訂通知標題。
- 自訂最多 2 / 3 / 4 列。
- 顯示百分比開關。
- 顯示欄位可選：今日損益、今日損益%、總損益、總損益%、總資產、總成本、成本損益、累積配息、更新時間、指定 ETF 損益。
- 指定 ETF 可複選。
- 設定頁提供通知假資料預覽。
- 點擊通知直接開啟每日損益頁。

## 6. 排版與背景
- 既有每頁 ⚙ 排版編輯器保留。
- 6 格格線：整列 / 1/2 / 1/3，同列拖曳規則保留。
- 新增可拖移的「浮動排版預覽」。
- 浮動預覽可切換：標準假數據 / 大金額 / 負損益。
- 假資料只用於預覽，不寫入真實資料。
- 設定頁新增相簿背景圖片、圖片透明度、背景遮罩與清除背景。

## 7. Google Vision OCR
- 保留 Google Vision OCR Only。
- 拍照 / 相簿 / 多筆交易 / 數學核實 / 批次加入均保留。
- 「顯示 OCR 進階設定」只控制設定介面，不會停用圖片掃描。

## 8. 品牌與預覽
- 保留新版 ETF財務管家 LOGO。
- `assets/previews/` 內附首頁、持倉、股息、每日損益、目標、情境、設定、智慧掃描的 UI 目標稿，供後續實機 UI 對照。

## 9. 資料與 OTA
- Storage Schema 升級至 11。
- runtimeVersion 仍為 1.5.0，本次屬於既有 Native baseline 可承接的 OTA 更新。
- initialized marker、舊資料優先、OTA 不覆蓋使用者資料的規則保留。

## Android 背景限制
前景 1～30 秒更新已套用。Android 不允許一般背景任務可靠地每 1～30 秒長時間執行；本版使用既有 BackgroundTask 做系統允許的背景行情 / Widget 更新。若未來要在 App 背景也強制秒級常駐，需要新增 Foreground Service 並重新建立 Native APK baseline。
