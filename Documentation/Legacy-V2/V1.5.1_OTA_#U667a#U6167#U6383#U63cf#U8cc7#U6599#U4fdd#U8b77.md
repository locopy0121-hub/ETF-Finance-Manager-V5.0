# V1.5.1 OTA 修正

- Runtime 基準：1.5.0（可由已安裝 V1.5.0 APK 接收 OTA）
- 智慧掃描：支援一張圖辨識多筆 ETF 候選交易，逐筆套入確認。
- 日期：支援西元、民國年、斜線/點/橫線、緊湊日期、部分月日推斷與合法日期驗證。
- OCR 容錯：全形字元與常見 0/O、1/I 類誤判正規化。
- 金額規則：股數整數、成交行情 2 位、購入成本/手續費/含費總成本四捨五入至整數元。
- 資料保護：新增 initialized 標記；既有安裝若狀態無法讀取，禁止重新灌入 seed/demo 資料。
- Schema：v5，舊資料透過 migration 保留。

注意：解除安裝 App 後，Android 私有資料仍可能被系統刪除；此情境需使用外部備份恢復。
