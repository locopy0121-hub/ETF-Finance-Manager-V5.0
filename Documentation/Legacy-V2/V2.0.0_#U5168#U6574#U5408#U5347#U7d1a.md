# V2.0.0 全整合升級

## 1. 單股 ETF 顯示模板
一份模板設定欄位與格寬，再複選要套用的 ETF。首頁不再為每檔 ETF 展開大量獨立資料項。

## 2. 設定頁瘦身
長設定改成 Accordion 收合；字體、對齊、主題、更新秒數與時間改用下拉選單 / 多選面板。

## 3. 色彩所見即所得
點色票後系統自動更新 HEX 色碼並即時套用；保留手動輸入 HEX。

## 4. 背景
支援頁面背景與卡片 / 框架背景圖片，並可調透明度與遮罩。

## 5. 全局字體與自動換行
全局字體 80%～160%。畫面文字不足時自動換行，避免文字被硬擠、裁切或省略。

## 6. 手續費與損益
手續費只進總成本。所有損益基於純買進成本，不把手續費另外扣進損益。

## 7. Widget / 通知 / OCR
保留 App Snapshot → Widget 的資料鏈；盤後通知可自由選資訊；Google Vision OCR 繼續使用，進階設定開關只控制技術欄位顯示。
