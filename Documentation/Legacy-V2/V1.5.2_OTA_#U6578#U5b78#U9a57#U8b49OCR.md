# V1.5.2 OTA — 數學驗證型 OCR

Runtime：1.5.0（可直接更新已安裝的 V1.5.0 基準 APK）

本版重點：

- 兩位小數數值優先判定為成交行情，例如 104.95。
- 帶千分位且無小數的整數列入股數／金額候選。
- 使用「成交行情 × 股數 ≈ 購入金額」做數學核實，容許四捨五入誤差。
- 若可核實「購入金額 + 手續費 ≈ 含費總成本」，進一步提高辨識信心。
- 日期支援西元、民國年、斜線、點號、連字號與短日期推定。
- 多筆掃描結果去重，低信心資料標示待確認。
- 新增「批次加入已核實資料」，只批次寫入 ETF、日期、股數、行情與數學驗證完整的紀錄。
- 同 ETF 會追加購入紀錄，不建立重複持倉。
- 批次加入前會檢查既有購入紀錄，疑似重複資料會略過。
- 成交行情保留兩位小數；股數、購入成本、手續費、含費總成本依既定規則四捨五入。
- OTA_PREVIEW.ps1 會在 node_modules 不存在時自動執行 npm install，避免 EAS plugin resolve 失敗。

注意：OCR 結果仍應在實機畫面確認；未通過數學核實的資料不會被「批次加入已核實資料」直接寫入。
