# V1.5.3 Google Vision Hybrid OCR OTA

## 目的
提升券商截圖的中文、數字與多筆交易辨識率。V1.5.3 同時執行：
- Google Cloud Vision `DOCUMENT_TEXT_DETECTION`（若已設定 Worker）
- 裝置端 ML Kit OCR

App 將兩邊結果各自送入既有交易解析與數學驗證，再依完整欄位、數學核實與信心分數選擇較好的結果。

## 安全架構
App 不保存 Google API Key。App 只保存 Cloudflare Worker URL；OCR shared token 使用 Expo SecureStore。Google API Key 與 OCR shared token 都以 Cloudflare Worker Secret 保存。

## Google Vision 的用途
Google Cloud Vision 回傳密集文件文字與文字位置。Worker 會依 bounding box 將字詞重新組成行，再交給 App 判斷：
- ETF 代號 / 名稱
- 日期
- `XXX.XX` 兩位小數行情候選
- `X,XXX` 無小數股數 / 金額候選
- `行情 × 股數 ≈ 成交金額`
- `成交金額 + 手續費 ≈ 含費總成本`

## OTA 相容性
runtimeVersion 保持 `1.5.0`，不新增 App 原生模組；V1.5.0 基準 APK 可直接接收本 OTA。

## 設定
先部署 `Cloudflare-Worker/google-vision-ocr-worker`，再到 App「資料與設定 → Google Vision Hybrid OCR」輸入 Worker URL 與 Token，按「測試連線」。
