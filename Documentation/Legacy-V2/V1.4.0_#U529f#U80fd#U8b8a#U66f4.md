# V1.4.0 功能變更

1. 購入日期全面改為月曆選擇。
2. 股息日的查看日期、最後買進日、除息日、股息發放日改為月曆選擇。
3. 目標頁可設定每月被動收入、每月投入、總資產、目標日期、假設殖利率、年化報酬率。
4. 首頁資產健康分數與下一筆配置可點擊查看算法；本月目標進度連結目標頁。
5. 本月投入改由實際購入紀錄彙整。
6. 持倉資料與購入紀錄支援左右滑動。
7. 新增每日損益頁與走勢圖。
8. 新增 13:35 預設收盤損益通知與背景 best-effort 任務。
9. Widget 新增總成本、成本損益、成本損益%、顯示欄位選擇、自選 ETF、透明度與深連結設定圖示。
10. OTA 維持每次工作階段只自動檢查一次。
