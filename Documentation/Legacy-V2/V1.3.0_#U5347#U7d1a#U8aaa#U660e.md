# ETF財務管家 V1.3.0 升級說明

## 本版核心修復
- 新增本機永久保存層：持倉、購入紀錄、手續費設定、股息月曆、OTA 設定、小工具設定都會保存。
- App 啟動先讀取本機資料；只有第一次安裝且完全沒有本機資料時才使用初始資料。
- OTA / 行情刷新不再重置真實庫存。
- 資料結構加入 schemaVersion 與 migration，後續欄位升級不應清空舊資料。

## OTA 規則
- EAS Update 啟動時自動檢查已關閉（checkAutomatically=NEVER）。
- App 啟動後依設定延遲，預設 5 分鐘，只檢查一次。
- 有更新時必須由使用者選擇「立即更新」或「本次略過」。
- 本次略過後，此工作階段不再自動檢查。
- 設定頁保留手動「立即檢查更新」。

## Android 即時損益桌面 Widget
- 新增 ETFProfit Android Home Screen Widget。
- 可由桌面自由縮放，總損益固定保留；尺寸越大顯示今日損益、總資產與更多 ETF 持有資料。
- 背景透明度可選 25 / 50 / 75 / 85 / 100%。
- 監看時段預設 09:00～13:30，可自行修改。
- App 開啟時 Widget 會隨 TWSE 行情同步刷新。
- Android AppWidget 系統週期更新的最短間隔為 30 分鐘，因此 App 完全關閉後的桌面背景更新由 Android 排程，不能保證每分鐘喚醒。

## 為什麼 V1.3.0 必須重建 APK
本版新增 @react-native-async-storage/async-storage 與 react-native-android-widget，屬於原生依賴，舊 V1.2.0 APK 無法只靠 OTA 加入。安裝 V1.3.0 基準 APK 後，後續純 JS/TS/UI 修正才可再使用 OTA。
