# ETF財務管家 V1.4.0 長期基準 APK

## 為什麼這版要重建 APK
V1.4.0 一次加入通知、背景任務、SVG 圖表、安全儲存、檔案選擇/分享、SQLite、裝置資訊等原生能力。這些能力不能從舊 APK 單靠 OTA 加入，所以本版作為新的長期原生基準。

## 後續通常可 OTA 的項目
畫面、排版、文案、財務公式、目標邏輯、每日損益呈現、股息月曆邏輯、Widget 顯示內容/排序、API JS 邏輯、資料 migration、圖表樣式、OTA 檢查流程。

## 後續仍可能需要 APK 的項目
Expo SDK / React Native 升級、增加尚未預埋的 native module、Android Manifest/權限模型改變、package id 變更、原生 Service/Receiver/Activity 新增、第三方 SDK 需要 Gradle 修改。

## 已預埋原生工具
- 通知與狀態列：expo-notifications
- 背景工作：expo-background-task + expo-task-manager
- 桌面 Widget：react-native-android-widget
- 本機檔案：expo-file-system
- 匯入檔案：expo-document-picker
- 分享：expo-sharing
- 安全儲存：expo-secure-store
- SQLite：expo-sqlite
- 網路狀態：@react-native-community/netinfo
- SVG 圖表：react-native-svg
- 生物辨識：expo-local-authentication
- 剪貼簿：expo-clipboard
- App/裝置資訊：expo-application + expo-device
- Android Intent：expo-intent-launcher
- 列印/PDF 基礎：expo-print

## 背景收盤通知限制
Android WorkManager 的背景任務不是精確鬧鐘。最小週期間隔為 15 分鐘，而且 Android 省電策略可能延後執行。App 開啟且收到有效 TWSE 行情時會立即補建立當日快照與通知。
