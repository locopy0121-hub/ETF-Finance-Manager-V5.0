# ETF財務管家 V1.5.0

## 智慧掃描新增庫存
- 可從相機拍攝或相簿選擇券商成交/持倉圖片。
- 使用 Android 裝置端 ML Kit OCR，預埋中文與 Latin 模型；圖片不需要送到外部 OCR 服務。
- OCR 後先解析 ETF 代號、成交日期、股數、成交行情、手續費，再由使用者確認。
- ETF 已存在時不建立第二筆持倉，只新增 PurchaseRecord 並重算總股數、總成本與平均成本。
- 偵測到相同日期、股數、成交行情與手續費時，先提示疑似重複購入紀錄。

## 新增後預覽
- 原本同列並排改成逐列直向顯示。
- 顯示購入日期、ETF、ETF名稱、新增股數、成交行情、購入成本、手續費、含費總成本。
- 既有 ETF 另外顯示原持有股數、本次新增、新增後總股數、原總成本、新增後總成本與新增後平均成本。

## APK / OTA
V1.5.0 新增 expo-image-picker 與 rn-mlkit-ocr 原生模組，因此需要重新建立並安裝一次 APK。安裝此基準 APK 後，OCR 解析規則、券商版型規則、預覽 UI 與重複交易判斷可優先透過 OTA 更新。
