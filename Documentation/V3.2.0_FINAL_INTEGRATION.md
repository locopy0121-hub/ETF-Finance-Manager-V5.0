# V3.2.0 最終整合範圍

本版整合 V3 實機測試累積項目：

1. 庫存修改 / 刪除 / 多筆購入紀錄。
2. 明確可點擊的 OTA 線上更新入口。
3. 卡片欄位取消選取數量上限。
4. 首頁 / 記帳 / 庫存 / 息收 / 試算 / ETF 詳情各自使用專屬完整欄位池。
5. Android Widget 保留並強化：多 ETF、欄位、字體、對齊、透明度、更新時間。
6. 盤後訊息設定：標題、行數、百分比、欄位、ETF、時間。
7. 時空試算恢復年 → 月（1~12 月）成長明細。
8. 我的存股計畫由提示入口升級為可建立 / 啟停 / 刪除 / 匯入 / 匯出資料模型。
9. 舊版持有庫存條件與股息回填整合回 V3。
10. 所有主頁 / BottomSheet / Modal / 底部 Tab 統一 Safe Area。
11. 息收頁恢復股息日、最後買進日、除息日、發放日、資格快照、預估 / 實際回填。
12. ETF 詳情卡片擴充成本 / 行情 / 損益 / 配息 / 權重 / 歷史 / NAV 狀態等資料。
13. 全局設定新增即時市場數據中心：TWSE、前景 1~30 秒、回前景刷新、最後更新與錯誤狀態。
14. 智慧記帳輸入 ETF 代號 / 名稱關鍵字可自動辨識名稱並嘗試取得 TWSE 最新行情。
15. Widget 前景 Snapshot 更新後自動 redraw，並保留背景系統排程更新。
16. 帳務引擎分離累積成交成本 / 買進手續費 / 現金支出 / 市值 / 價格損益 / 含費損益。
17. 盤後通知消除損益與百分比重複列，依設定行數截取。
18. 各頁卡片資訊層級、寬度、欄位池與自由排版整體優化。
19. 時空試算可直接以「目前持有庫存快照」作為模擬起點，並與未來規劃比較；不修改真實庫存。

另外新增：各頁標題列 AI 財務助理入口、本機自然語言記帳確認卡與帳務 / 損益查詢。
