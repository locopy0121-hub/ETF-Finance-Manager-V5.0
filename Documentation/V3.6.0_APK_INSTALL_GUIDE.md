# ETF財務管家 V3.6.0 NATIVE APK 建置與安裝

## 首次建置
在 PowerShell 進入專案根目錄：

```powershell
powershell -ExecutionPolicy Bypass -File .\BUILD_V3.6.0_APK.ps1
```

腳本會：安裝缺少依賴 → 跑 V360 audit → TypeScript typecheck → Expo dependency check → Android prebuild → 檢查 V3.6.0 Native manifest → 送出 EAS preview APK。

## 安裝
EAS 完成後用輸出的 Expo Build 連結下載 APK。V3.6.0 runtime 與 V3.5.0 不同，因此這次不是 OTA，必須安裝新的 APK baseline。

## 後續 OTA
只有 JS/TS/圖片等不改 Native 的內容，才使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\OTA_V3.6.0_PREVIEW.ps1
```

如果變更 Kotlin、AndroidManifest、App Icon aliases、Receiver、Widget Native、原生權限或原生 module，必須重新執行 APK build。
