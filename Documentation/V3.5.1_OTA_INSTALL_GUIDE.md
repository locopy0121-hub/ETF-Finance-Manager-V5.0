# V3.5.1 OTA 安裝 / 更新指南

## 使用前提
V3.5.1 是 OTA 更新，不是新的原生 APK。手機必須已安裝 **V3.5.0 FIX1 APK**，其 Expo runtime 必須是 `3.5.0`。

## 發佈 OTA
1. 將 ZIP 解壓縮到 Windows 資料夾。
2. 開啟 PowerShell 並切換到專案根目錄。
3. 執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\OTA_V3.5.1_PREVIEW.ps1
```

4. 腳本會自動：
   - 安裝 npm dependencies（如果本機尚未有 `node_modules`）
   - 執行 V3.5.1 audit
   - 驗證 Finance Engine / Formula Engine / 股息規則
   - 執行 TypeScript semantic check
   - 執行 Android Expo Metro/Hermes export
   - 通過後才執行 EAS preview OTA

## 手機端套用
發佈完成後依 App 既有 OTA 檢查流程套用更新。此版不要求重新安裝 APK。

## 何時不能用 OTA
若後續修改以下項目，必須重新建置 APK：
- Kotlin / Java 原生程式
- AndroidManifest 權限或 Service
- Android Widget Provider 原生設定
- 新增需要 native linking 的套件
- runtimeVersion 改變

## 資料安全
V3.5.1 不重建持倉、帳務、股息或設定資料庫；既有資料應原地保留。正式更新前仍建議使用 App 內備份功能保留一份資料副本。
