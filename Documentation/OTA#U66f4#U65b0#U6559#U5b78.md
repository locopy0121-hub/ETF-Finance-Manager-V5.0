# OTA 更新教學

第一次安裝 V1.2.0 APK 後，後續 JS/TS、UI、計算邏輯與一般資產調整可使用 EAS Update。

## Preview 測試
PowerShell 執行：
`powershell -ExecutionPolicy Bypass -File .\OTA_PREVIEW.ps1`

## Production
確認 Preview 正常後：
`powershell -ExecutionPolicy Bypass -File .\OTA_PRODUCTION.ps1`

## 必須重建 APK
Expo SDK / React Native 升級、加入或修改原生模組、Android 權限、package/applicationId、原生設定等不能只靠 OTA。
