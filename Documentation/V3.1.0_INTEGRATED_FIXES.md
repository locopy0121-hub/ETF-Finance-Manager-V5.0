# ETF財務管家 V3.1.0 整合修正版

本版本依 2026-09-08 實機驗收問題清單一次整合，不採逐項熱修。

## 已整合項目
1. 庫存：修改、刪除、多筆購入紀錄、券商/帳戶、已賣出股數保留。
2. 線上更新：全局設定內明確的「立即檢查線上更新」。
3. 卡片資料：取消欄位數量上限。
4. 各頁專屬欄位池：首页、記帳、庫存、息收、試算、ETF 詳情分開設定。
5. Android Widget：多 ETF、欄位、字體、對齊、透明度、更新時間與 Snapshot。
6. 盤後訊息：標題、時間、2/3/4 行、欄位、指定 ETF。
7. 時空試算：恢復「年 → 1~12 月」展開明細，年化率換算月複利率。
8. 我的存股計畫：模擬可真正建立計畫，支援啟停、刪除、匯入、匯出，且與真實庫存隔離。
9. 舊版庫存條件與股息回填：資格股數快照、預估/實際股息、事件 ID 去重。
10. Safe Area：主頁、底部 Tab、BottomSheet、Modal 以 react-native-safe-area-context 統一處理。
11. 息收頁：恢復股息日、最後買進日、除息日、發放日、股息回填與配息事件管理。
12. ETF 詳情：持有/成本、行情、損益、配息、權重、交易紀錄、NAV/折溢價資料狀態等完整欄位池；無可靠資料不造假。
13. 市場數據設定：TWSE、1~30 秒前景更新、僅盤中高頻、回前景立即刷新、最後更新與錯誤狀態。
14. 完整資料備份/還原：V3 JSON schema 驗證與匯入摘要確認。
