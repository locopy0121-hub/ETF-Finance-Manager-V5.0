# TWSE LIVE 行情層

目前 `src/services/twse.ts` 使用 TWSE 基本市況報導網站（MIS）的盤中資料介面取得指定 ETF 行情，並將價格提供給庫存計算引擎。

## 更新規則
- App 啟動立即查詢。
- 每 15 秒自動刷新一次。
- 使用者可在總覽 / 持倉 / 資料中心手動刷新。
- 只要 TWSE 回傳有效價格，App 所有市值與未實現損益都以 TWSE 計算。
- 若 TWSE 暫時無回應，保留最後有效行情；首次啟動且尚未取得行情時才使用 seed 價格。

## 正式化前注意
TWSE MIS 是 TWSE 官方即時市場資訊網站的資料來源；若未來要對外商用、再散布即時/延遲交易資訊或大量使用，應依 TWSE 最新授權與資料服務規範辦理。此專案目前定位為個人內測工具。
