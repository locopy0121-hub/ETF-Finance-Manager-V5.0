# V3.0.0 實機驗收清單

- [ ] APK 可安裝並顯示 V3 深色首頁。
- [ ] V2 持倉首次進 V3 能正常載入。
- [ ] 首頁不再出現「你付出多少 / 現在得到多少 / 目前損益多少」。
- [ ] 首頁主卡片欄位可在設定中自由勾選。
- [ ] 四個內建背景可切換，自訂相簿背景可套用。
- [ ] 卡片透明度、圓角、全局字體比例可調。
- [ ] Android 底部導覽沒有被系統導航列遮住。
- [ ] 智慧記帳買進同一 ETF 可新增多筆。
- [ ] 賣出不可超過目前股數；部分賣出後平均成本保持不變。
- [ ] 配息入帳會增加 Ledger 與現金，不會在總資產重複加兩次。
- [ ] 現金存入不會被誤計為投資獲利。
- [ ] Dashboard 圖表可正常顯示。
- [ ] Portfolio Donut 可正常顯示。
- [ ] Dividends 12 月堆疊圖與生活 Gauge 正常。
- [ ] Calculator 更改本金 / 月投 / 年期 / 報酬後立即更新。
- [ ] Widget 在 App 前景更新後可同步最新 snapshot。
- [ ] OTA 在開 App 後依設定延遲，只自動檢查一次。
