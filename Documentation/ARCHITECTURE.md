# ETF Pilot 資料架構

## 核心原則

```
交易紀錄 / 持有股數 / 平均成本
          │
          ▼
     App 成本引擎
          │
          ├──────────────┐
          │              │
          ▼              ▼
       TWSE 行情      情境模擬資料
       最終來源       永久隔離
          │
          ▼
   即時未實現損益
```

1. 平均成本不從行情供應商取得。
2. TWSE 是最終行情與價格核對來源。
3. Yahoo Finance 僅能是輔助，不能覆寫 TWSE。
4. TWSE 暫時失效時顯示最後有效價格，並標示資料狀態。
5. 模擬結果不得回寫真實庫存。
