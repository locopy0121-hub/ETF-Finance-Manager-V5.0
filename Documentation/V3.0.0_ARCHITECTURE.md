# ETF財務管家 V3.0.0 架構

## 五大主頁

- 資產總覽：正式財務名稱、可自訂主卡片欄位、資產成長圖、資產配置圖、隱私模式。
- 智慧記帳：買進 / 賣出 / 配息入帳 / 現金提存四類 Ledger。
- 庫存清單：市值 / 損益 / 權重排序、ETF Drill-down、折溢價 Gauge 入口。
- 息收日曆：配息總覽、12 月堆疊圖、生活目標 Gauge、待入帳紀錄。
- 時空試算：有效年化率轉月複利、投入 vs 資產成長圖、導入存股計畫前確認。

## 統一帳務觀念

V3 不允許各頁自行發明損益公式。首頁、庫存與圖表共用 `src/v3/engine.ts`。

- 成交金額 = 股數 × 成交行情
- 買進總投入成本 = 成交金額 + 買進手續費
- 目前總資產 = 持股總市值 + 帳戶現金
- 配息與賣出款若已進入現金部位，不可在總資產再次重複加總
- 現金存入 / 提領屬外部資金流，總損益計算會中和，不把存款誤認為投資獲利

## 視覺系統

預設深色微光風格。主題與資料層分離；背景圖片、卡片透明度、圓角與字體比例不會改變帳務資料。

## 圖表系統

`src/v3/charts.tsx` 使用 `react-native-svg`，避免把核心財務圖表做成 WebView。圖表資料由統一帳務層或每日快照提供。
