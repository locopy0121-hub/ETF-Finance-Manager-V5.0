# V3.0.2 OTA 更新按鈕修正

## 修正內容
- V3 全局設定中心新增「OTA 更新」分頁。
- 新增「立即檢查 OTA 更新」按鈕。
- 可啟用/關閉進入 APP 後自動檢查 OTA。
- 自動檢查延遲可選 1 / 5 / 10 / 15 分鐘，預設沿用 5 分鐘。
- 手動檢查會明確顯示：目前已是最新版本、偵測到更新、更新下載失敗、Expo Updates 未啟用等狀態。
- 修正設定底部按鈕仍使用 Safe Area，不被 Android 導航列遮擋。

## APK / OTA
此修正未新增 Native module，維持 `runtimeVersion: 3.0.0`，可由 V3.0.0 APK 直接接收 OTA。
