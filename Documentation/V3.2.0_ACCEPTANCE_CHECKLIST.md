# ETF財務管家 V3.2.0｜整合驗收清單

本清單對應 2026-09-08 實機測試累積的主要需求，供 APK 安裝後逐項驗收。

## 核心帳務
- [ ] 成交金額只等於股數 × 成交價，不含手續費。
- [ ] 累積成交成本、累積買進手續費、累積現金支出分開顯示。
- [ ] 目前市值 = 即時行情 × 目前持有股數。
- [ ] 總資產 = 持股市值 + 現金；手續費不列入資產。
- [ ] 價格損益與含費損益分開。
- [ ] 部分賣出、賣出費 / 稅、股息不重複計算。

## 資產總覽 / 卡片
- [ ] 首頁核心卡片可自行選不限數量欄位。
- [ ] 各頁有專屬完整欄位池。
- [ ] 卡片支援整列 / 1/2 / 1/3 / 1/4、拖曳排序、自動增高。
- [ ] 背景、卡片背景、透明度、圓角、字體與色彩仍可設定。
- [ ] 圖表可看到投入 vs 資產、資產配置等資料。

## 智慧記帳 / 庫存
- [ ] 輸入 ETF 代號或名稱後可帶入名稱與 TWSE 行情（網路可用時）。
- [ ] 同 ETF 可累積多筆買進紀錄。
- [ ] 庫存可修改、刪除，購入紀錄可逐筆編輯。
- [ ] 買進、賣出、配息、現金四種帳務入口可用。

## 息收
- [ ] 最後買進日 / 除息日 / 發放日 / 每股配息可管理。
- [ ] 資格股數保存快照。
- [ ] 預估股息與實際入帳可回填，事件不重複計入。
- [ ] 月月配息圖與被動收入資訊可顯示。

## 時空試算 / 存股計畫
- [ ] 可從目前持有庫存只讀快照開始。
- [ ] 可自由建立不限檔數 ETF 組合與配置比例。
- [ ] 年化報酬正確換算月複利。
- [ ] 股息可選回投原 ETF / 集中指定 ETF / 依配置比例。
- [ ] 年度結果可展開 1~12 月。
- [ ] 存股計畫可建立、啟停、刪除、匯入、匯出；不修改真實庫存。

## Widget / 通知 / OTA / 行情
- [ ] Widget 可選多 ETF、欄位、字體、透明度、對齊。
- [ ] App 前景行情刷新後 Widget 重新繪製。
- [ ] 盤後通知可設定欄位、2/3/4 行、百分比、ETF 與時間。
- [ ] 設定中心有「立即檢查線上更新」。
- [ ] 市場數據設定可設定自動更新、前景 1~30 秒、盤中模式、回前景刷新。

## AI 財務助理
- [ ] 各核心頁標題列可開啟 AI 助理。
- [ ] 「今天購入0050 109.50 500股 手續費10元」可解析並先顯示確認卡。
- [ ] 「今日損益」可列出各 ETF 與總計。
- [ ] AI 寫入真實資料前必須確認。

## Android 實機
- [ ] 3 鍵導航 / 手勢導航下，Bottom Tab、設定、Modal、BottomSheet 按鈕不被系統導航列遮擋。
- [ ] 關閉 / 重開 App 後資料仍存在。
