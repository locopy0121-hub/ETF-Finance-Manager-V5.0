# ETF財務管家 V5.0.3 — 360 Block Editor

V5.0.3 upgrades the 360 editor from fixed cells to free-position blocks while preserving the existing grid/template contract.

## Locked specification

- Single tap selects a block type; long press opens full editing.
- Blocks support free position, width/height, drag movement, nudge controls, layer ordering and per-block lock.
- ZERO OVERLAP remains the default hard gate; explicit free-layer mode allows overlapping, including blocks placed over charts.
- Saving a template locks it. Editing requires an explicit unlock.
- Preview supports 50/75/100/125/150% display zoom without changing saved layout dimensions.
- Internal binding/schema keys are hidden from the normal editor UI.
- Cell appearance adds block background, text background, border, palette presets and dynamic color sources.
- Dynamic colors support fixed/theme/P&L/market modes. P&L defaults are gain red, loss green and flat yellow.
- Version chain: 5.0.3 / Android versionCode 50003 / app build 50.
