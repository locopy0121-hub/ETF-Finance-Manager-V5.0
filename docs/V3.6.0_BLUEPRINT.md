# V3.6.0 NATIVE 改版藍圖

## 0. 全 APP 總體稽核
先檢查首頁、智慧記帳、持倉、息收、每日損益、時空試算、ETF 詳情、設定、Global Editor、圖表、浮動監視器、Widget、AI、通知、Native、資料層、版本/OTA 分界。

## 1. Global Editor 2.1
- 編輯設定必須真正 Style Binding。
- 個別欄位 > 單一卡片 > 頁面 > 主題 > 系統預設。
- 編輯器採獨立 Modal：基本 / 顏色 / 版面 / 特效 / 預覽。
- 儲存後重新讀取設定並實際套用成功才關閉。

## 2. Floating Monitor Native 2.0
- 表格/拼圖共用 fieldStyles。
- ETF 代號、行情、今日損益、庫存損益可獨立設定。
- 自訂排序、桌面鎖、排程、開機恢復。
- 與 Widget 啟動生命週期完全解耦。

## 3. Settings Layout 2.1
- 第二層 Tab 使用 minHeight、自適應行高與 Padding。
- 支援水平滑動，不硬塞一排。
- Modal / BottomSheet / 表單完整 safe-area。

## 4. Chart Engine 2.1
- 首頁圖表單擊切換真正重新 Renderer。
- 長按進入個別圖表編輯。
- 記住最後使用圖表型態。

## 5. AI Assistant 3.0
- Context + Tools + Diagnostics + Actions。
- 最近一次/最近三次/今年/下次/歷史等查詢 scope。
- App 診斷模式與 Debug 問題回報包。
- 舊跨 APP BOT 清除，由浮動監視器取代。

## 6. App Icon Center
10 組內建圖示，可在 App 內切換本 App Launcher Icon。

## 7. Widget Native Pro
